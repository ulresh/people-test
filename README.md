# Человечки

Android-приложение (`com.github.ulresh.people_test`, minSdk 27): определяет положение
корпуса, головы, рук и ног у людей в кадре с камеры (в том числе USB), ведёт треки
перемещения людей и рисует для каждого человека схематичную фигурку, повторяющую его позу.

Создано на основе `usb-camera` (звук и трансляция в сеть убраны).

## Как работает

- Кадр с камеры (YUV) берётся целиком, обрабатывается, показывается; затем берётся
  самый свежий кадр — промежуточные теряются. Доля обработанных кадров выводится
  в настройках рядом с частотой кадров.
- Поза: MoveNet MultiPose Lightning (TensorFlow Lite), до 6 человек, 17 точек.
  Кисти и ступни дорисовываются приближённо.
- Треки: жадное сопоставление по расстоянию между центрами; у каждого подтверждённого
  трека своя ячейка фигурки (и цвет), фигурки не перемещаются вслед за людьми.
- Экран слева: сверху кадр (рамки, скелеты, траектории), снизу фигурки.

## Сборка

Модель в репозиторий не входит, её скачивает скрипт (с Kaggle):

```
scripts/download-model.sh [http://адрес-прокси:порт]
gradle assembleDebug      # app/build/outputs/apk/debug/app-debug.apk
```
